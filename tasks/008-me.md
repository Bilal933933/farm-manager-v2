# Task 008: بناء Me - بياناتي (User + Company + Permissions)

## الهدف
بناء `GET /api/auth/me` يعرض بيانات المستخدم الحالي + شركته + دوره وصلاحياته، بنمط `Controller->Action->Resources`.

## الملفات المطلوبة
- `microservices-demo/services/auth-service/app/Actions/Auth/MeAction.php` (جديد)
- `microservices-demo/services/auth-service/app/Http/Resources/MeResource.php` (جديد)
- `microservices-demo/services/auth-service/app/Http/Controllers/AuthController.php` (تعديل - إضافة me)
- `microservices-demo/services/auth-service/routes/api.php` (تعديل - إضافة route)

## خطوات التنفيذ

### 1. MeAction
```php
// app/Actions/Auth/MeAction.php
namespace App\Actions\Auth;
use App\Models\User;
class MeAction {
  public function execute(User $user): User {
    return $user->load(['company','role.permissions']);
  }
}
```

### 2. MeResource
```php
// app/Http/Resources/MeResource.php
namespace App\Http\Resources;
use Illuminate\Http\Resources\Json\JsonResource;
class MeResource extends JsonResource {
  // $this->resource هو User مع company, role.permissions
  public function toArray($request): array {
    return [
      'user' => new UserResource($this->resource),
      'company' => $this->resource->company ? new CompanyResource($this->resource->company) : null,
      'role' => $this->resource->role ? [
        'name' => $this->resource->role->name,
        'slug' => $this->resource->role->slug,
        'permissions' => $this->resource->role->permissions->pluck('name'),
      ] : null,
    ];
  }
  public function with($request): array { return ['success'=>true]; }
}
```

### 3. AuthController::me
```php
// app/Http/Controllers/AuthController.php - إضافة
use App\Actions\Auth\MeAction; use App\Http\Resources\MeResource;

public function me(Request $request, MeAction $action) {
  $user = $action->execute($request->user());
  return (new MeResource($user))->response();
}
```

### 4. Route
```php
// routes/api.php - إضافة
Route::middleware('auth')->get('/auth/me', [AuthController::class, 'me']);
```

## معايير القبول
- [ ] `GET /auth/me` بدون تسجيل دخول يرجع `401`
- [ ] `GET /auth/me` بعد `login` يرجع `200 {user, company, role:{name,permissions:[28]}}`
- [ ] Super Admin `company=null` يرجع `company: null, role: super_admin`
- [ ] لا منطق في Controller - فقط `Action->execute()`
